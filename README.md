# Matrix Studio

Статический сайт-калькулятор для матриц: сложение, вычитание, умножение, транспонирование, определитель, обратная матрица, ранг, след, RREF, а также решение систем методом Крамера и Гаусса с отображением шагов.

## Запуск
C:/Users/bessa/AppData/Local/Temp/Rar$EXa38920.15427/matrix-toolkit-main/index.html
1. Скачайте проект ZIP, распакуйте и откройте папку в VS Code.
2. Откройте `index.html` в браузере или запустите через Live Server.

Для `Ax = b` введите квадратную матрицу коэффициентов A и вектор b одним числом на строку. Нажмите «Крамер» или «Гаусс»: ответ и подробный ход решения появятся справа.
